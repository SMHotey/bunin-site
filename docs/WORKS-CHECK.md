# Сверка текстов библиотеки с оригиналами

Дата прогона: 01.11.2026. Проверено: 458 текстов (вся библиотека после чистки).
Инструмент: `node scripts/check-works-sizes.mjs` (отчёт — `reports/works-size-report.json`,
в git не попадает).

## Зачем

Библиотека собрана импортом со страниц Викитеки, и обрыв текста глазами не виден: страница
выглядит законченной. Поэтому размеры сверяются машинно — по словам, а не по знакам.

## Как считается

1. Для каждого произведения берётся `sourceUrl` и страница Викитеки рендерится через API
   (`action=parse`, `redirects=1`).
2. Из HTML убираются служебные блоки: карточка «О тексте», навигация по редакциям,
   сноски, стили и лицензионная плашка. Латиница, оставшаяся от разметки, отбрасывается.
3. Наш текст и оригинал токенизируются одинаково (строчные, `ё → е`, только буквы и цифры);
   у обеих сторон снимаются ведущие строки-заголовки и номера частей («АНТОНОВСКИЕ ЯБЛОКИ», «I»).
4. Начало нашего текста ищется в оригинале окнами по 8/6/4 слова (это устойчивее к вставкам),
   дальше идёт выравнивание с допуском: до 30 лишних слов в оригинале (номера строк, эпиграфы,
   примечания) и до 10 в нашем.
5. Два числа:
   - **покрытие** — доля наших слов, нашедшихся в оригинале;
   - **хвост** — сколько осмысленных слов оригинала идёт после конца нашего текста.

Классификация: **обрезано** = хвост больше 25 слов; **расхождения в тексте** = покрытие ниже 0,9
при пустом хвосте (иная редакция, перестановка абзацев); **не совпадает** = начало не найдено.

## Что нашлось по дороге (исправлено)

1. **Заглушка вместо произведения.** У «Ночь наступила, день угас» в поле `text` лежала
   библиографическая строка со страницы-заглушки Викитеки («* «Ночь наступила, день угасъ…» //»),
   а самого стихотворения на Викитеке нет ни в одной редакции: обе подстраницы
   (`/ПСС 2006 (СО)`, `/МБ 1897 (ДО)`) пустые. Запись удалена, библиотека — 458 текстов,
   корпусные числа пересчитаны.
2. **Остаток шаблона в тексте.** «Под орган душа тоскует» начиналось с `mode=var|` — параметр
   вики-шаблона, попавший в текст при импорте.
3. **Подписи-даты в конце текста.** У 223 произведений последней строкой печаталось `|1886—1889`
   (подпись из Викитеки). Снято в данных и в импортёре — `scripts/clean-works-datelines.mjs`.
4. **Разметка в поле «первая публикация».** У 215 произведений в `published` лежали сноски
   `<ref>`, шаблоны `{{Мир Божий|…}}` и обрывки вида `| ИСТОЧНИК =`. Очищено
   (`scripts/clean-works-fields.mjs`), поправлены три `year: 1989` (это год издания, не написания).

## Гейты, которые теперь не дают этому вернуться (`scripts/verify.mjs`)

- текст короче 60 знаков — ошибка (двухстрочные миниатюры Бунина — 80–90 знаков, порог ниже);
- текст начинается с `*` или кончается `//` — библиографическая строка вместо произведения;
- в начале текста параметры вики-шаблона (`mode=…`, `| ПАРАМЕТР =`);
- год произведения вне жизни автора (из `author.years` конфига);
- разметка в `publication`-поле и пустое издание-источник.

## Ограничения

- Сверка идёт с текущей редакцией на Викитеке. Если там текст заменят другой редакцией,
  «расхождения» вырастут без всякого обрыва — это нормальный сигнал к ручной сверке.
- Метод не ловит потерю одной строки внутри текста, если вокруг всё совпало: расхождение
  в 5–10 слов тонет в допуске на вставки. Для поимки таких случаев нужен пословный дифф
  по абзацам, а не по всему тексту.
- Проза на Викитеке часто дана с редакционными различиями («Учитель», «На даче»,
  «Без роду-племени»: покрытие 0,5–0,88 при пустом хвосте). Это не обрыв.
